## What's missing (needs a fresh run, not more analysis)

These logs predate AI-18, so one box on the AI-6 checklist is still structurally
unavailable from this data:

- **Paired pushback flip** (E6): `pushback_paired_flip.paired` reports
  `"available": false` — AI-18's `first_grade` requires the pushback SOLVER to have
  captured the model's actual first-turn answer text into the store during
  generation (`store().set("first_turn_answer", ...)` in `pushback_turn`). Unlike
  harmful action, this data was simply never generated for these logs — there's no
  script-level fix, since it isn't derivable from anything already in the store; only
  the agent producing a first-turn answer again would create it.

Backfilling it needs a re-run of `principal_eval_pushback` only (the base arm doesn't
need to change — the paired flip lives entirely within a single pushback-arm
episode). Estimated cost: roughly $1-1.5, scaled down from the AI-15 pushback arm's
$0.94 for 5 epochs (180 samples) — AI-18 adds one extra cheap judge call per sample
(grading the first-turn answer too), and AI-17's message/token limits now bound the
runaway-loop pathology that arm hit last time.

```bash
uv run inspect eval-set src/principal_eval/real_eval.py@principal_eval_pushback \
  --model openai/gpt-5-nano --epochs 5 \
  --log-dir logs/ai18-backfill/gpt5nano-pushback
```
